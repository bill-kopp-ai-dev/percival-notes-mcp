Para que "scan limpo" seja gate de verdade, o operador precisa fixar severidade de rejeição na política do host (`POSITRONIC_EXECUTOR_MAINTENANCE_POLICY_FILE`). Decisão do owner em 2026-11-08: não criar gate paralelo no GitHub Actions, para não duplicar o gate do host.
